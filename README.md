# Voices

iOS 15+ 的 UIKit 声音工作室业务原型，采用深色界面。基础录音与回放使用系统 AVFoundation，目前没有第三方依赖、模型服务或网络上传。

## 已实现

- 我的声音：与已确认原型一致的深色空态与声音卡片，录音授权、实际音量波形、停止与试听、暂停续播、命名保存、选择样本、重命名与删除。
- 实时变声：圆形录音操作、目标样本选择、真实原声试录和回放、命名保存。AI 音色转换明确显示为待接入，试录不会伪装为变声结果。
- 文字朗读：编辑文稿、自动保存本机草稿、选择声音样本，以及明确标记的生成、取消、播放、暂停、拖动和重播交互演示。演示不合成或播放音频；结果保留生成时的声音和文字，修改后提示重新生成。
- 当前页面没有声音时直接创建，保存后回到原页面并自动选中；已有声音时可在选择弹层切换或新增。
- 录音进入后台或遇到中断时停止，保留可用片段供当前页面保存；切换页面不会继续采集。朗读演示切页或进后台也会停止。
- 声音样本在 Application Support/VoiceLibrary 中以 M4A + JSON 保存。没有预置或伪造声音样本。

## 工程结构

- `Voices/Core`：录音、播放和声音库持久化，独立于业务页面。
- `Voices/Features`：三个业务页面与录音弹窗。
- `Voices/UI`：深色样式、波形、样本选择与页面基础组件。
- `Voices/SceneDelegate.swift`：原生程序化页面入口。

第三方模型后续接在基础能力层，业务页面继续由本项目维护。当前尚未选定供应商、通信协议或端侧模型。

## 运行

用 Xcode 打开 `Voices.xcodeproj`，选择 `Voices` scheme 和 iPhone 模拟器运行。真机运行需在 Signing & Capabilities 选择你的开发团队。

```sh
xcodebuild -project Voices.xcodeproj -scheme Voices \
  -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/voices-prototype-deriveddata \
  CODE_SIGNING_ALLOWED=NO build
```

## 验收重点

1. 首次录音出现麦克风授权；拒绝后显示设置入口，可正常返回。
2. 录制、停止、试听并保存；重新打开 App 后样本与选择仍在。
3. 保存空名称应提示；放弃录音需确认，已保存样本不会受影响。
4. 录音中切换页面或进入后台，不应继续采集。
5. 编辑文稿后重启 App，草稿仍在；生成演示可取消，结果保留原文和声音，播放可暂停、拖动和重播，所有状态注明无真实音频。
6. 在真机验证实际声音质量、蓝牙耳机路由和系统来电中断。
7. 从变声或朗读页进入声音创建，保存后仍在原页面；选择和删除声音会同步到各页。

最低部署版本为 iOS 15.0；当前开发机没有 iOS 15 模拟器运行时，仍需在该版本设备上补充运行验证。
